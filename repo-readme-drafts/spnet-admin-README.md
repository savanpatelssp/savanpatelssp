# SP NET ADMIN OS

Enterprise administration platform from **SP NET INC** — role-based permissions, audit
logs, analytics, and moderation for managing organizations at scale.

## What this is

The operational backbone of the SP NET ecosystem. SP NET ADMIN OS is web native, built to
run organizations and platforms with precision: who can do what, what happened and when,
and how the system is performing.

## Capabilities

- **Role-based access control** — fine-grained permissions across roles and resources
- **Audit logs** — trace actions and decisions
- **Analytics** — usage and performance metrics
- **Moderation** — review and governance tooling
- **Dashboarding** — operational views with charts and reporting

## Tech stack

- Next.js 16 (App Router) · React 19 · TypeScript
- Prisma 6 · PostgreSQL
- shadcn/ui · Radix UI · Tailwind CSS 4
- NextAuth · Zod · Recharts
- Vitest · Playwright
