# SP NET — Website

Official website for the **SP NET** parent organization ([sp-net.in](https://sp-net.in)).

SP NET is the parent organization under which **SP NET INC** operates, building a private,
self-owned ecosystem of products — communication, ownership, and community — across web,
mobile, messaging, and blockchain.

## What this is

The public face of the ecosystem. It introduces the organization, its founding philosophy,
and the products being built: **SP NET GRAM**, **SP NET ADMIN OS**, and the SP NET Platform
underpinning them.

## Tech stack

- Next.js 16 (App Router) · React 19 · TypeScript
- Tailwind CSS 4 · Framer Motion
- Deployed on Vercel

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm run start
```
