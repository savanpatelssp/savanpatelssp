# SP NET HELPDESK

Enterprise support platform from **SP NET INC** — conversation-first helpdesk that unifies
email, WhatsApp, and live chat into one workspace.

## What this is

A business communication platform built around conversations, not tickets. Support teams
handle customer threads across every channel from a single interface, with email (IMAP)
integration as the foundation.

## Capabilities

- **Conversation-first** — thread-based support workspace
- **Multi-channel** — email, WhatsApp, and live chat
- **Email integration** — IMAP mailbox sync
- **Transactional notification** — Resend

## Tech stack

- Next.js 15 (App Router) · TypeScript
- Prisma 6 · PostgreSQL · Redis
- Resend · Sentry
- Vitest
