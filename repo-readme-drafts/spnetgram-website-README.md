# SP NET GRAM — Website

Official website for **SP NET GRAM**, a messaging platform from **SP NET INC**.

## What this is

The product site for the communication pillar of the SP NET ecosystem — a messaging
experience focused on privacy, premium features, organizations, coins, gems, and platform
services.

## Sections

Homepage · Platform overview · Beta program · Development portal · Status center ·
Roadmap · Newsroom · Documentation · Careers · Support · Early access waitlist

## Tech stack

- Next.js 16 (App Router) · React 19 · TypeScript
- Tailwind CSS 4

## Development

```bash
npm install
npm run dev
```

## Status

Live at [spnetgram.com](https://spnetgram.com).
