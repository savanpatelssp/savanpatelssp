## About the Organization

**SP NET** ([sp-net.in](https://sp-net.in)) is the parent organization. Under it operates **SP NET INC** ([spnetinc.com](https://spnetinc.com)) — a company building a private, self-owned ecosystem of products. Every platform shares a common foundation — TypeScript, Next.js, React, PostgreSQL, Node.js — and a common discipline: engineering that is precise, tested, and designed with restraint.
